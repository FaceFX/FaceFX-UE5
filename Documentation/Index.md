SGX|FaceFX UE5 Plugin Documentation
===================================

First, make sure you have read over the SGX|FaceFX UE5 Plugin [README](../README.md), specifically the information concerning the [LICENSE](../LICENSE.md).

The Documentation is organized into the following main sections:

+ [Requirements and Key Concepts](RequirementsAndKeyConcepts.md) - Details the requirements and key concepts needed to use and understand the plugin. **Read this first**.

+ [Setup](Setup.md) - Details the setup process for FaceFX Unlimited, the SGX|FaceFX UE5 plugin, and UE5 character setup.

+ [Iteration](Iteration.md) - Once your character is setup and has successfully been imported into Unreal Engine 5, you will no doubt want to iterate on that character and its animations. This section details that process.

+ [Blueprint Nodes](BlueprintNodes.md) - Details the Blueprint nodes made available by the plugin.

+ [Sequencer](Sequencer.md) - Details the integration with Sequencer.

+ [Events](Events.md) - Details how to use events.

+ [Configuration](Configuration.md) - Details plugin configuration options.

+ [Context Menus](ContextMenus.md) - Details the additional items added to right-click context menus for assets.

+ [Linking and Unlinking Animations](LinkingAndUnlinkingAnimations.md) - Details what linking and unlinking animations means.

+ [Errors and Warnings](ErrorsAndWarnings.md) - Details the various errors and warning generated by the plugin.

+ [Troubleshooting](Troubleshooting.md) - Details solutions to common problems with using the plugin.
